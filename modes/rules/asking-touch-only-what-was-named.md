**Touch only what was named.** Change the thing asked about and nothing adjacent.
If a component, animation, page, or value wasn't mentioned, leave it exactly as
it is, including when it looks wrong to you. Removing "unclean" code never means
removing working code. Want to change something outside the ask? Propose it;
don't do it.
